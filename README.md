🌐 **Live Demo**: [aura-powder.vercel.app](https://aura-powder.vercel.app)

---

## 🚀 Technologies & Innovation

This project leverages modern web technologies to deliver a premium, app-like experience:

- **React 18 & TypeScript**: For a robust, type-safe, and interactive user interface.
- **Vite**: Lightning-fast build tool ensuring optimal development and production performance.
- **Tailwind CSS**: Utility-first styling for a fully responsive, aesthetic, and custom design system.
- **Progressive Web App (PWA)**: Installable on any device (iOS, Android, Desktop) providing a native app feel with offline caching via Workbox.
- **Vercel Deployment**: Seamless and fast global edge delivery.
- **Bilingual Architecture**: Dynamic RTL/LTR layout switching for Arabic and English users.
- **Dark/Light Mode**: Smooth theme transitions complementing the brand identity.

## 🛠 Getting Started for Developers

Make sure you have [Node.js](https://nodejs.org/) (v18+) installed.

```bash
# Clone the repository
git clone https://github.com/mna80455-debug/-Aura-basmala-mohammed-.git
cd -Aura-basmala-mohammed-

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📱 PWA Installation

This website is a **Progressive Web App (PWA)**:
- **Desktop (Chrome/Edge)**: Click the install icon in the address bar.
- **Mobile (Android)**: Tap "Add to Home Screen" from the browser menu.
- **Mobile (iOS)**: Tap Share → "Add to Home Screen" from Safari.
